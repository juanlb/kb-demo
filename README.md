# kb-demo

Demo project for the `knowledge-base` plugin of the [itcrowd marketplace](https://github.com/itcrowdarg/skills).

- `docker compose build` builds a Node image that compiles a native module (`bcrypt`) from source.
- `tools/slug.py` is a small Python helper with tests in `tools/test_slug.py`.
- `.claude/settings.json` enables the `knowledge-base` plugin for everyone who opens the project in Claude Code.
